# Synthetic examples

These tracked examples are reusable design inputs for an Agent. They never contain real project paths, registrations, repository URLs, credentials, logs or reports.

- `static-service.config.json` demonstrates a static service descriptor.
- `service-shapes.json` contains inactive descriptor fragments for frontend, backend/API, detached service, environment-owned WebUI/API ports, command readiness, observability, and optional Git registration notes.

Real service configuration belongs in the workspace reported by `scripts/init_dashboard.py`.
